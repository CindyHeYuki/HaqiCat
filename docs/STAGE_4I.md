# 阶段 4I：哈气比例与过渡返修

本轮针对三相哈气中爆发帧突然变大、前后角色比例不统一以及动作硬切的问题进行返修。

## 原因

- 原三张素材按每格可见边界分别缩放，不同姿势会得到不同的实际人物倍率。
- 爆发帧在绘制时还额外使用了 `1.015×` 放大和 2 像素上移，进一步放大了跳变。
- 蓄势、爆发和收势之间没有中间姿势，只能直接切换轮廓。

## 修正

1. 重制五张素材：蓄势、起身过渡、爆发、回落过渡、收势。
2. 五格使用共同裁切框、共同缩放倍率和共同画布位置，不再逐格缩放。
3. 生成时锁定头部、眼睛、花饰、耳朵、手掌和衣服比例，并保持相同视角。
4. 使用 12 拍序列 `0, 0, 1, 1, 2, 2, 2, 3, 3, 4, 4, 4`，总时长仍为 960 毫秒。
5. 删除爆发帧的额外缩放与整体上移，只保留约 1 像素的横向轻震。

## 验证

- 自动测试：20 项全部通过。
- 原生 Windows 窗口逐帧捕获到五个正确索引，动作结束后恢复待机。
- 五帧耳朵顶线、头部和面部尺寸保持一致，过渡由姿势变化完成，不再依赖整体缩放。
- 五张最终素材均为 256×256 RGBA PNG，素材清单 SHA-256 校验通过。
