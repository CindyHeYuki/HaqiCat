# 阶段 4E：低趴观察后的起身过渡

本轮继续消除低趴观察结束后直接切换站立待机的姿态跳变。

## 动作时序

1. 低趴观察计时结束后保持原方向。
2. 第一帧用双臂撑起胸口，后腿仍折叠贴地。
3. 第二帧转向正面半跪，双手离地，准备进入站立姿态。
4. 起身阶段持续约 640 毫秒，然后切换到普通待机。

## 实现

- 新增左右各两帧的透明起身素材。
- 新增 `rise_left`、`rise_right` 与 `rising_active` 状态。
- 起身动画继续复用 80 毫秒运动计时器，每帧保持四个刷新周期。
- 拖动、点击、哈气、休息和新的自主行为都会安全取消起身状态。
- 新增素材分割与镜像工具 `tools/split_rise_sheet.py`。

## 验证

- 自动测试：17 项全部通过。
- 原生窗口验证：成功显示撑起帧和半跪帧，并在 640 毫秒后恢复
  `idle` 与 `autonomous_mode=idle`。
- 透明、无边框、置顶和 256×256 画布保持正常。
