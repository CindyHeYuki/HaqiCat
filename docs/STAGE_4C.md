# 阶段 4C：贴地四足爬行

本轮废弃直立走路表现，把自主移动改成更符合哈气猫形象的低姿态四足爬行。

## 动作依据

- PLOS ONE 的猫隐蔽步行研究指出，低姿态步态会让四肢高度屈曲、身体重心贴近
  地面，并通过更均匀的落足节奏提高潜行稳定性。
- 侧视动作参考显示，猫移动时头部相对稳定，主要变化来自肩胛、背线和骨盆。
- 猫的后爪会追入同侧前爪刚离开的区域，形成窄而重叠的足迹。

参考资料：

- https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0003808
- https://motionzoo.net/cat-walk-reference/
- https://pmc.ncbi.nlm.nih.gov/articles/PMC4137248/

## 本轮实现

- 新增左右各四帧的透明爬行素材。
- 自主状态由 `walk_left` / `walk_right` 改为 `crawl_left` / `crawl_right`。
- 每 80 毫秒更新一次位置，每次移动 2 像素；每张动作帧保持三个更新周期。
- 移除旧走路额外叠加的上下弹跳与旋转，让身体变化由爬行帧本身表达。
- 保留随机移动、移动后观察、屏幕边缘转身、拖动和落地缓冲逻辑。
- 新增素材分割与左右镜像工具 `tools/split_crawl_sheet.py`。

## 验证

- 自动测试：14 项全部通过。
- 原生窗口冒烟测试：透明、无边框、置顶、256×256 画布均正常。
- 强制播放爬行测试：成功进入 `crawl_right`，四帧全部加载，并在运行中推进到
  第 3 帧。
