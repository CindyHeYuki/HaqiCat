# 阶段 4A：随机走动与观察

本轮建立第一个自主行为状态机，继续复用现有单张走路立绘。

## 行为循环

1. 待机 4–8 秒
2. 约 72% 概率随机向左或向右走 24–52 小步，其余情况哈气
3. 每 80 毫秒移动 3 像素，并用轻微上下起伏模拟步伐
4. 走完后停下约 1.4 秒，歪向行进方向观察
5. 回到待机，再安排下一次行为

## 边缘与互动优先级

- 下一步会超出当前屏幕工作区域时，保留剩余步数并原地转身
- 靠近边缘开始走动时，会优先选择空间更充足的方向
- 拖动、哈气和休息会立即打断走动或观察
- 趴睡期间不安排自主行为

这一阶段先验证行为节奏和边界逻辑。真正的腿部逐帧走路、眨眼和哈气动画
将在后续素材阶段制作。
