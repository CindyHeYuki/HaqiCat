# 阶段 4G：三相哈气动画

本轮把原先单张哈气图配合整段左右抖动，升级为具有身体重心变化的三相动作。

## 动作时序

1. 压低身体蓄势：耳朵后压、四肢收紧、尾巴开始炸起。
2. 张口炸毛哈气：双爪前伸、身体弹起，只在这一段加入轻微横向震动。
3. 低伏收势：嘴巴合拢、爪子落下，仍保持戒备姿势，再恢复站立待机。

三帧各保持 4 个 80 毫秒刷新周期，完整动作约 960 毫秒。动画沿用现有低频运动计时器，不新增高频循环。

## 素材处理

- 使用现有待机与哈气造型作为角色参考，通过内置图像生成制作同视角三格动作表。
- 原始生成结果采用纯绿色背景，经过软边透明化、去绿边、逐格内容裁切和 256×256 画布归一化。
- 新增 `tools/split_hiss_sheet.py`，保证三张最终素材采用相同底线与可见高度。
- 最终素材为 `haqi_cat_hiss_01.png` 至 `haqi_cat_hiss_03.png`，并在素材清单中记录 SHA-256。

## 验证

- 自动测试：19 项全部通过。
- 原生 Windows 窗口：分别截取并确认蓄势帧、爆发帧和收势帧均正常显示。
- 三个检查点均保持透明、无边框、置顶、可见以及 256×256 窗口尺寸。
- 动作结束后恢复 `idle`，哈气帧索引归零，后续随机行为可继续安排。
