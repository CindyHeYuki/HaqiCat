# 阶段 4D：爬行收势与低趴观察

本轮消除爬行结束后瞬间切回直立待机的跳变。

## 动作时序

1. 爬行步数归零后保持原方向。
2. 播放约 320 毫秒的收势帧：前爪收回、四肢靠拢、臀部压低。
3. 切换到低趴观察帧：胸口和视线略微抬高，但身体仍保持四足贴地。
4. 低趴观察阶段仅保留轻微呼吸缩放。
5. 观察总计约 1.8 秒后恢复普通待机，并重新安排下一次自主行为。

## 实现

- 新增左右各两帧的透明观察素材。
- 新增 `observe_left` 和 `observe_right` 状态。
- 使用现有 80 毫秒运动计时器推进过渡，没有增加高频计时器。
- 点击、拖动、哈气或休息会安全取消观察，并清理观察计时状态。
- 新增素材分割与镜像工具 `tools/split_observe_sheet.py`。

## 验证

- 自动测试：16 项全部通过，包括休息中断低趴观察的状态清理。
- 原生窗口验证：成功从第 1 帧推进到第 2 帧，保持
  `observe_right` 和 `autonomous_mode=observe`。
- 透明、无边框、置顶和 256×256 画布保持正常。
