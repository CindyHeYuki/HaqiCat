# 阶段 4F：无抖动随机眨眼

本轮为站立待机增加自然眨眼，同时保持较低的常驻资源占用。

## 动作时序

1. 每隔 2.5 至 7 秒随机安排一次眨眼。
2. 依次显示半闭眼、闭眼、半闭眼，每帧保持两个 80 毫秒刷新周期。
3. 整段眨眼约 480 毫秒，完成后恢复睁眼并安排下一次随机眨眼。
4. 非待机状态不会播放眨眼；若眨眼被哈气、拖动或其他行为打断，会安全清理
   当前帧并重新安排。

## 素材处理

图像生成工具提供半闭眼和闭眼的眼睑参考。为避免生成图轻微重绘身体导致帧间
抖动，最终素材以原始待机 PNG 为底，只对齐并合成两个眼部区域。头发、花饰、
耳朵、身体、衣服、四肢和尾巴均保持原始像素。

## 实现

- 新增半闭眼与闭眼两张透明素材。
- 新增单次随机眨眼计时器，不使用轮询或高频空转。
- 使用现有运动计时器推进半闭、全闭、半闭三相序列。
- 新增素材对齐工具 `tools/build_blink_frames.py`。

## 验证

- 自动测试：18 项全部通过。
- 原生窗口验证：成功显示半闭眼与闭眼帧，身体轮廓保持稳定。
- 眨眼结束后 `blink_active=false`，下一次单次计时器保持活动。
- 透明、无边框、置顶和 256×256 画布保持正常。
