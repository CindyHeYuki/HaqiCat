# 阶段 3A：无控制台启动与互动动作

本轮专门改善启动体验和桌宠的生命感，不加入随机走动。

## 无黑色窗口启动

双击项目根目录的 `HaqiCat.vbs`。启动器使用虚拟环境中的
`pythonw.exe`，不会保留命令提示符窗口，也不修改系统设置。

`run_haqicat.cmd` 继续保留，用于开发时查看诊断输出。

## 动作

- 待机：约 12.5 FPS 的平滑呼吸、上下浮动和轻微摇摆
- 哈气：短暂放大并左右抖动
- 趴睡：约 5 FPS 的缓慢呼吸
- 拖动：鼠标指针切换为张手和握手状态

## 互动

- 单击：哈气
- 双击：趴睡或恢复待机
- 左键拖动：移动桌宠
- 右键：手动哈气、休息、恢复或退出
