# 阶段 4H：落爪同步爬行节拍

本轮针对爬行时角色姿势不变却持续匀速滑动的问题，让窗口位移与四帧爬行动画同步。

## 节拍设计

- 一轮四相爬行包含 12 个 80 毫秒刷新周期。
- 位移序列为 `1, 0, 1, 2, 3, 2, 1, 0, 1, 2, 3, 2` 像素。
- 两个落爪相位各包含一次短暂停顿，避免脚爪接触地面时继续滑行。
- 两个探身相位承担主要前移距离，形成轻微加速和重心转移。
- 左右方向共用同一节拍，碰到屏幕边缘后仍会转身并从第一相重新开始。

## 姿态处理

四个爬行相位分别附加不超过 1.2 像素的上下偏移、约 0.6% 的缩放变化和不超过 0.45 度的方向性前倾。变化保持克制，以加强肩背受力感，同时避免重新出现夸张摇摆。

这部分继续复用现有 80 毫秒运动计时器，没有新增高频计时器或忙循环。

## 验证

- 自动测试：20 项全部通过。
- 新增位移节拍测试，确认实际步进含停顿且不是等速移动。
- 原生 Windows 窗口记录到一轮连续位移差为 `1, 0, 1, 2, 3, 2, 1, 0, 1, 2, 3`。
- 原生截图确认落爪与探身姿势正常，窗口保持透明、可见及 256×256 尺寸。
