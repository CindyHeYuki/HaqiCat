# 阶段 3B：拖动拎起动作

本轮只增强拖动反馈，不加入新的自主行为。

## 动作设计

拖动立绘参考用户提供的哈气猫实物图与当前待机立绘，通过内置图像生成工具
制作。角色后领/后颈位置作为不可见的受力点，四肢和尾巴自然下垂，不显示
人的手、绳子或挂钩。

生成时使用纯绿色键控背景，再进行软边去背、去绿边和 256×256 画布适配。
最终透明素材位于 `assets/character/processed/haqi_cat_drag.png`。

## 交互

- 鼠标移动超过拖动阈值后才切换动作，普通单击不会闪烁拖动立绘
- 进入拖动时，角色顶端中央会吸附到鼠标下方，形成从背后拎起的感觉
- 拖动期间加入轻微悬摆，而不是完全静止
- 松开左键后立即恢复原有状态与动画
