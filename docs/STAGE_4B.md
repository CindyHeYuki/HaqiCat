# 阶段 4B：多帧走路循环

本轮把左右走动从“单张立绘平移”升级为真正的循环帧。

## 帧结构

每个方向使用四个动画相位：

1. 原有第一侧迈步帧
2. 新增收腿经过帧
3. 新增反侧迈步帧
4. 再次使用收腿经过帧，平滑返回第一帧

每帧保持两个 80 毫秒刷新周期，因此走路动画约为 6.25 FPS。角色仍然每次
刷新移动 3 像素，帧切换和窗口位移共用原有计时器，没有新增高频计时器。

## 素材

新增的两张左向帧使用内置图像生成工具制作，输入为当前左向走路和待机立绘。
素材先生成在纯绿色键控背景上，再执行软边去背、去绿边、统一脚底基线和
256×256 画布适配。右向帧由左向透明素材无损镜像生成。
